# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.4] — 2026-10-31

### Added
- Кнопка закрытия (крестик) у каждого файла в списке с корректным пересчётом индексов.
- Контекстное меню (ПКМ) по списку файлов: «Очистить список» и «Закрыть все, кроме текущего».

### Changed
- Локализация новых элементов интерфейса (RU/EN).
- Версия поднята до 1.0.4.

## [1.0.3] — 2026-10-31

### Added
- Иконка окна и панели задач: параметр `icon` в `BrowserWindow`
  (`icon/bubble.ico`), чтобы вместо стандартной иконки Electron показывался логотип.
- Иконка включена в список файлов сборки (`files: "icon/bubble.ico"`).

### Changed
- Корневая рабочая папка переименована в `BubbleCutter_Work`.
- Версия поднята до 1.0.3.

## [1.0.2] — 2026-10-31

### Added
- Миниатюры (40×40) в списке файлов: для png/jpg/webp — превью,
  для SVG — квадратик с текстом «SVG».
- Иконка для `.exe` (`win.icon`), многоразмерный `bubble.ico` (16–256 px).

### Changed
- Версия поднята до 1.0.2.

## [1.0.1] — 2026-10-30

### Added
- Три вкладки над холстом: Контуры / PhotoCraft / Диагностика; сайдбар всегда видим.
- Загрузка папки: добавление всех изображений (png, jpg, webp, svg) в галерею.
- Режимы после сохранения: переход к следующему изображению или остаться на текущем.
- Локализация интерфейса и меню (Русский / English) с мгновенным переключением.
- Меню Electron: Файл / Правка / Вид / Справка, переключатель языка, «О программе».
- Сохранение пути к PhotoCraft в `userData/photocraft_path.json` с автопоиском.

### Changed
- Кнопка «Открыть папку PhotoCraft» перенесена на вкладку PhotoCraft.
